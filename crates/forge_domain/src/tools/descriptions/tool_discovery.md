Search the catalog of tools and skills this agent may load but does not have yet, or load one by its id.
- An empty `query` returns a compact index (ids, names, sources; capped at 4 KiB). A search ranks rows by BM25 over names, descriptions and parameter names and adds short descriptions (capped at 8 KiB). `kind` (native, mcp, skill) and `source` (an MCP server's name, `native`, `skill`, or `mcp` for every server) narrow the rows. When `truncated` is true, repeat the call with `offset` set to `next_offset`.
- `load` takes the `id` of a row whose `loadable` is true, or a tool's bare name. Loading a tool publishes its full schema from the next model call on, for the rest of this conversation. Loading a skill returns its instructions and loads the tools it declares that this agent may use. Searching with `kind="mcp"`, `source="mcp"` or an MCP server's name as `source` connects to those servers first; a server that is not connected yet or failed to connect appears as a status row, which is not loadable.
- Load first, then call the tool in a later response: a tool is not callable in the same response that loads it. Calling a tool that is not loaded returns an error naming the exact load call.
