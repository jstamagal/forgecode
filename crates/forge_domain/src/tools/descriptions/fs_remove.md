Move a file, directory or symlink to the trash, or delete it with `permanent=true`. Either way the path is snapshotted first, so `{{tool_names.undo}}` can bring it back. Symlinks are removed as symlinks, never followed. The trash uses `trash` or `trash-put`; when neither is installed or the command fails, nothing is removed and `permanent=true` is the way to remove the path. Anything over 512 MiB is refused rather than trashed; confirm with the user before deleting that with `permanent=true`.
