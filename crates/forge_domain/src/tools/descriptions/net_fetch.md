Fetch a URL over HTTP(S) or `file://`.

HTML comes back as markdown with links made absolute, so you can fetch them as-is; `raw=true` returns the source instead. `method`, `headers`, `body` and `json_body` make any HTTP request (a GET that saves nothing checks robots.txt first). `save` streams the body to that path instead of returning it, with no size limit; a partial download left by an interrupted save resumes with a Range request, and the previous file at that path can be brought back with `{{tool_names.undo}}`. Binary responses come back as a short descriptor naming the type and size; pass `save` to get the bytes. Images come back as images when the model accepts image input. Unsaved responses are read up to 32 MiB and bounded by a 30-second timeout; a large text result is written to a file whose path and continuation range the result names.
