Convert one file for a wiki vault: text, code and structured text are returned as text; PDFs through `pdftotext`; office and ebook formats through `pandoc` (or `soffice`); images come back as an embed plus any text `tesseract` reads from them (a missing tesseract is reported as OCR unavailable). Images and audio/video are copied into `<vault>/assets/` when `vault` is given (it must exist). The model decides what pages to write; this only converts input and copies media.
